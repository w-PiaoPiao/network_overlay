# 网络状态悬浮窗 (Network Overlay)

屏幕角落显示实时网络连接状态的小工具，支持覆盖游戏、全屏应用和全屏播放器。

## 功能

- **📶 网络状态显示** — 优先显示 WiFi SSID + 信号强度，fallback 到以太网/其他连接
- **🔓 拖动模式** — 解锁后左键拖动到屏幕任意位置，拖动时边框高亮提示
- **🔒 锁定模式** — 锁定后位置固定并**真正鼠标穿透**（点击直达下层应用，不影响游戏/全屏）
- **🖥 系统托盘图标** — 圆点颜色随网络状态变化；左键切换锁定，右键弹出完整菜单（锁定穿透后的操作入口）
- **🔅 透明度可调** — 右键菜单或滚轮调节（20% ~ 100%）
- **🔤 字号可调** — 9px ~ 16px，信号图标随字号自动缩放
- **⏱ 自动刷新** — 默认每 1 秒检测网络变化
- **💾 记忆位置** — 位置和所有设置自动保存到 `overlay_config.json`
- **☑ 开机自动启动** — 内置选项，通过注册表实现（无需手动创建快捷方式）
- **💬 悬停提示** — 鼠标悬停显示连接类型、信号强度、锁定状态等详情
- **🚫 单实例** — 不会重复启动多个

## 快速开始

### 方式一：双击运行
直接双击 `network_overlay.pyw`（无命令行窗口启动）

### 方式二：批处理
双击 `启动悬浮窗.bat`

### 方式三：静默启动
双击 `启动悬浮窗(静默).vbs`（完全无窗口闪现）

### 开机自启

**内置方式（推荐）：**
右键悬浮窗 → 右键菜单 → 点击「☐ 开机自动启动」即可一键开启/关闭。
（通过 Windows 注册表 HKCU 实现，无需管理员权限，无需创建快捷方式。）

**手动方式（备选）：**
1. 按 `Win + R`，输入 `shell:startup` 回车
2. 把 `启动悬浮窗(静默).vbs` 的快捷方式复制进去

## 操作说明

| 操作 | 效果 |
|------|------|
| 右键悬浮窗 | 打开设置菜单 |
| 左键拖动（🔓状态） | 移动位置（拖动时边框高亮） |
| 点击🔒图标 | 切换锁定/解锁 |
| 点击✕ | 弹出确认菜单，确认后退出（防误触） |
| 滚轮 | 调整透明度 |
| 悬停悬浮窗 | 显示连接详情（类型/信号/锁定状态/刷新间隔） |
| 左键托盘图标 | 切换锁定/解锁 |
| 右键托盘图标 | 弹出完整设置菜单 |

> 注意：锁定状态下悬浮窗**真正鼠标穿透**（所有点击直达下层应用），
> 请使用**系统托盘图标**解锁或退出。首次启动会显示一次操作提示气泡。

## 右键菜单

- **切换锁定/解锁** — 锁定后鼠标穿透，不影响下层操作
- **透明度** — 50% / 65% / 75% / 85% / 95%（单选标记显示当前值）
- **字号** — 9px ~ 16px（单选标记显示当前值）
- **刷新间隔** — 1 / 2 / 3 / 5 / 10 秒（单选标记显示当前值）
- **手动刷新** — 立即刷新网络状态
- **管理 WiFi 分类** — 打开分类管理窗口，对连接过的 WiFi 打钩分类
- **开机自动启动** — 勾选框显示当前状态，一键切换
- **重置位置** — 回到屏幕右上角
- **退出** — 关闭悬浮窗

## 状态颜色

- 🟢 绿色 — WiFi 已连接且分类为"绿色类"
- 🔴 红色 — 首次连接的 WiFi（默认）或分类为"红色类"
- ⚪ 灰色 — 有线/其他连接
- ⬜ 灰字 + 红色 ✕ 图标 — 无网络连接（与红色类 WiFi 的文字红区分开）

## WiFi 分类管理

所有 WiFi 首次连接时默认为**红色类**。
右键菜单 → "📋 管理 WiFi 分类" 打开管理窗口：
- **打钩** ☑ — 将该 WiFi 设为绿色类，连接时显示绿色
- **取消打钩** ☐ — 将该 WiFi 设回红色类，连接时显示红色
- **点击 🗑** — 从记录中删除该 WiFi（不再保留分类记录）
- 分类立即生效并自动保存，连接记录会持久保留
- 当前连接的 WiFi 会高亮显示并带有绿色圆点标记
- 按 `Escape` 或 `Return` 可快速关闭管理窗口

## 需求

- Windows 10 / 11
- Python 3.7+ （系统自带 tkinter）
- 无需安装第三方库
- 网络检测通过原生 Win32 API（wlanapi.dll / iphlpapi.dll）实现，无需 PowerShell 子进程
